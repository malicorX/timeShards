# Release v0.2.0 — Go-Live UX & UI refactor

**Tag:** `v0.2.0` · **Date:** 2026-06-02

## Summary

Second milestone on the TimeShards **time foundation**: production go-live tooling, slimmer admin/client UIs, and operational KPIs for Zeit vs. Zutritt.

## Highlights

- **Go-Live-Assistent** — step-by-step dialog on server Übersicht (env, Zeitbasis reparieren, Personal, Stundenzettel, Zeit↔Zutritt).
- **Produktions-Checkliste** — live status for demo mode, passwords, calendars, Soll, mismatches.
- **Dashboard** — `time_access_mismatch_count` and per-employee mismatch list.
- **Reports** — timesheet HTML export with **Tagesdetails**; Lohn-CSV with Berlin month bounds.
- **UI refactor** — server tabs and client pillars (`ClientAppShell`, login/settings views).
